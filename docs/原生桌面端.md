# 原生桌面端

## 定位

`desktop/` 是 SpiritScout 的主桌面客户端，使用 Kotlin Compose
Desktop 与 SaltUI 3.0.0。界面运行在原生 Skia 窗口中，不使用 WebView2，也不把浏览器
标签页当作产品界面。

`packaging/windows/build-desktop.ps1` 负责打包，`packaging/windows/build-backend-runtime.ps1` 只负责
Python embeddable 运行时。旧的 WebView2、WinForms 兼容壳和单文件尾载荷流程已删除。

## 桌面能力

- 仪表盘、系统资源与执行概况。
- 任务创建、附件上传、任务列表和任务工作区。
- 工作区内发送消息、暂停、继续、结束，并按 3 秒周期同步任务状态。
- 管理员登录页，兼容设置了管理员账号的后端。
- 项目、资产、编队、模型、MCP、Skill、本地工具、资产情报、代理、浏览器账号、
  流量、自动任务、经验和设置页面。
- 经验页支持搜索、来源会话跳转、删除、相似经验整理与撤销；会话经验页支持手动提炼。
- 新建任务支持项目、代理方案、资产策略、排除资产、平台、Flag 格式、赛制、RPS、
  预算、CTF 提示、无模型模式、浏览器账号、文件/文件夹/剪贴板附件和规则冲突确认。
- 会话工作区提供对话、文件、拓扑、资产、机会、赛题、漏洞、Flag、经验、流量、
  后台任务、事件、运行记录、交付物和报告标签页；支持审批、回答 Agent 提问、
  子 Agent 旁路对话、切换模型、重命名、切换项目和删除会话。
- 流量页提供 HTTP/WS 筛选与原文下载、PCAP/PCAPNG 导入、实时抓包、Wireshark
  display filter、协议树、文本/Hex/ASCII、TCP/UDP 流追踪和会话代理控制。
- Skill、MCP、项目、自动任务、浏览器账号和模型提供原生新建、编辑、删除；
  代理池提供订阅、导入、固定方案、测速和删除；本地工具提供配置、刷新和清理。
- 设置页提供主题、中文/英文、动效、通知、会话存储清理、更新检查和高级 API 控制台。
- 英文目录覆盖桌面端全部静态中文文案，并由 `DesktopI18nCoverageTest` 强制校验。
- 经验页可打开随包附带的 `tools/experience-export` 快照工具；桌面包内可用
  `py\python.exe tools\experience-export\export_experience.py` 导出或回灌经验。
- Skill、资产和经验接口按 `limit=100` 自动翻页。Skill 当前共 298 条，
  不会停在接口默认的 40 条。

## 启动结构

`Main.kt` 创建 SaltWindow；`AppController` 负责：

1. 定位 Python 运行时；
2. 选择随机回环端口；
3. 启动 `python -m spiritscout --host 127.0.0.1 --port <随机端口>`；
4. 等待后端就绪并创建 `SpiritApi`；
5. 把 Python 后端加入 Windows Job Object，并附加父进程 watchdog；
6. 关闭窗口时结束整棵 Python 子进程树；强制结束桌面进程时 Job Object 也会回收后端。

桌面日志位于 `%LOCALAPPDATA%\SpiritScout\desktop-logs`。

## 构建

需要 JDK 21。首次构建会下载 Gradle、Compose 和 SaltUI 依赖。

```powershell
$env:JAVA_HOME = '<你的 JDK 21 安装目录>'   # 需要 JDK 21
.\desktop\gradlew.bat -p .\desktop run
```

生成 Windows 应用目录和 zip：

```powershell
powershell -ExecutionPolicy Bypass -File packaging\windows\build-desktop.ps1
```

构建流程会：

- 从 `src/spiritscout/__init__.py` 读取唯一版本号；
- 调用 `packaging/windows/build-backend-runtime.ps1` 生成内嵌 Python 后端运行时和配置模板；
- 生成包含全部运行时依赖的 staging 目录；
- 使用 Compose 精简 JRE；
- 调用 JDK 21 `jpackage` 生成 `SpiritScout.exe`；
- 复制现有 Python 便携运行时和配置；
- 压缩成可分发的 Windows zip。

`stageDesktop` 会按 Maven group/module/version 重命名依赖 JAR，避免
`androidx.lifecycle` 与 `org.jetbrains.androidx.lifecycle` 的同名文件互相覆盖。

## 验证

```powershell
$env:JAVA_HOME = '<你的 JDK 21 安装目录>'   # 需要 JDK 21
.\desktop\gradlew.bat -p .\desktop test
```

发布前还需从解压目录直接启动 `SpiritScout.exe`，确认：

- 窗口标题为 `灵枢 · SpiritScout`；
- 仪表盘加载出会话和系统资源；
- Skill 页显示 298 项；
- 关闭窗口后 Python 后端进程退出。

自动冒烟：

```powershell
.\packaging\windows\smoke-desktop.ps1 `
  -AppDir .\build\windows-desktop\package\SpiritScout
```

脚本会检查后端 HTTP 就绪、WebSocket 依赖、桌面进程退出和后端进程树释放；只结束本次
启动得到的进程。

## 功能对齐边界

桌面端所有 Web 导航模块均有原生页面，正式业务操作使用专用控件。设置中的高级 API
只作为附加诊断入口，不能替代模型、Skill、任务、资产、流量、MCP 等正式页面。

## 签名

Windows SmartScreen 对未签名 exe 仍可能显示“发布者未知”。这需要受信任的
Authenticode 代码签名证书，不是 Compose 或 SaltUI 能绕过的部分。
