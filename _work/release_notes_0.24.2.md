## 本次发版：0.24.0 → 0.24.2

三件事：CTF 不再拦输入、修好了提交后附件复活的 bug、补了一份打包说明。

### 主要变化

- **CTF 模式不再做输入完备性校验**。以前选 CTF 却没给赛题清单、没写 URL、
  没传附件、也没有平台档案，创建会话会被直接拒掉，让人对着表单反复猜缺哪一项。
  现在一律放行：什么都没有就拿任务原文当题面，缺的信息由灵枢运行期自己问。
  SRC 模式的目标校验保留 —— 没目标真的无处安放，模型再问也变不出来。
- **修复：提交任务后附件没真正清掉**。`bindAttach` 捕获的是数组引用，而提交
  后写的是 `S.homeFiles = []`（换新数组），闭包从此攥着孤儿数组：下次选文件
  push 进去，把上一轮提交过的附件又画回来；登记状态永远是空的，发送键恒灰，
  提交时附件静默丢失。改成就地清空。会话输入坞同一个写法一并修掉。
- **新增《打包与产物说明》**（`docs/打包与产物说明.md`）：包体用途、逐层结构、
  runtime 为何占 655 MB、构建时剥 tests 与 editable 残留各防什么、启动脚本每个
  环境变量的用途、三步构建为何 zip 排最后、拿到包后的自检顺序。
- **便携包预置做题经验**：`experience.db` 里 8 条实战判读经验随包发出。

### 变更明细

## [0.24.2] - 2026-10-31

- **新增《打包与产物说明》**（`docs/打包与产物说明.md`），把「打出来的包是什么」
  写成一份能独立看懂的文档：三种产物各给谁（便携包给最终用户、wheel 给开发者、
  sdist 给审源码的人）；便携包四个顶层目录的分工与逐层内容；`runtime\` 为什么占
  650 MB、`python.exe` 为什么必须放在该层根上；构建时剥掉 `tests/` 与
  `__editable__*.pth` 各自防的是什么；`configs\system.yaml` 里五个路径键被改写
  成 `data/workspace/...` 的原因；`data\` 出厂状态与运行后长出来的完整结构；
  启动脚本每个环境变量的用途（尤其 `PYTHONNOUSERSITE` 与
  `LITELLM_LOCAL_MODEL_COST_MAP`）；三步构建为什么 zip 必须排最后；以及拿到包
  后的自检顺序和四种起不来现象的归因。文档里的体积与文件数都是实测值
  （28564 个文件 / 3870 个目录 / zip 28562 条目），不是估算。

## [0.24.1] - 2026-10-31

- **修：提交任务后附件没真正清掉，下次选文件会复活**。`bindAttach` 在模块加载
  时就捕获了 `S.homeFiles` 的数组引用，而提交成功后原先写的是 `S.homeFiles = []`
  ——换了个新数组。闭包从此攥着一个孤儿数组，后果连着三条：下次选文件时 `push`
  进的是旧数组，`renderFileChips` 把上一轮已经提交过的附件又画回来；登记状态永远
  是空的，发送键恒灰；提交时 `[...S.homeFiles]` 取到空快照，附件静默丢失。现在
  统一走新增的 `clearFileChips()` 就地清空（`files.length = 0`），闭包与状态始终
  指向同一个数组。会话输入坞的 `S.compFiles` 是同一个写法，一并修掉。
  新增 `tests/test_attach_clear.js` 锁住这个契约：清空后引用不变、DOM 同步清空、
  清空后再选文件不会带出旧附件、提交快照读得到当前真实状态。

## [0.24.0] - 2026-10-31

- **CTF 不再校验输入完备性，点了执行就开工**。以前选 CTF 模式却没给赛题清单、
  没写 URL、没传附件、也没平台档案，创建会话时会被直接拒掉，让人对着表单反复
  猜「到底缺哪一项」。现在一律放行：有清单用清单，有 URL 按 URL 合成题，有附件
  按离线题合成，什么都没有就拿任务原文当题面（行首一句作标题，全空时给中性壳）。
  缺的信息由灵枢在运行期自己开口问——它比表单更清楚该问什么。SRC 模式的目标
  校验保持不变：没目标真的无处安放，模型再问也变不出来。
- **便携包预置做题经验**。`.spiritscout/experience.db` 里积累的实战洞察现在随包
  发出，收包的人开箱就带着这批判读经验，不用从零攒。新增内容都是「怎么判读」
  而非「打什么」：云靶场实例回收后坐标失效、连接超时在按需实例上应先当成实例
  生命周期信号、零轮次战报不能当作难度或防护证据、赛事入口令牌过期与靶场下线
  难以区分、赛事接入层与题目实例层可达性互不蕴含。README 与包内使用说明都新增
  了「做题经验包含什么」一节，讲清知识库（`security_skills.json` + `seed.py`，
  随 `app/` 分发）与经验库（`experience.db`，预置 + 收尾自增长）两层结构、
  字段含义，以及归零与迁移办法。
